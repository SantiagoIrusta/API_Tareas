# Proyecto API de Tareas

Este es un proyecto simple de backend usando **Node.js** y **Express** para gestionar tareas. El frontend es una interfaz de usuario sencilla con **HTML** y **CSS**.

## Funcionalidades

- Crear tareas.
- Ver tareas existentes.
- Marcar tareas como completadas.
- Eliminar tareas.

## Tecnologías utilizadas

- Node.js
- Express.js
- HTML
- CSS

## Instrucciones

1. Clona este repositorio.
2. Ejecuta `npm install` para instalar las dependencias.
3. Ejecuta `node server.js` para iniciar el servidor.
4. Accede a la aplicación en `http://localhost:3000`.
